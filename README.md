Project Overview

An AI voice agent built using Retell AI for preliminary Loan Against Property (LAP) eligibility assessment.

Features

- Customer greeting and loan offer explanation
- Property type and ownership verification
- Original property document verification
- Loan amount and occupation verification
- Income credited to bank account verification
- Property market value and loan tenure collection
- Preliminary eligibility outcome and specialist handoff

Technology

- Retell AI
- AI voice agent
- Prompt engineering

Testing

Tested with different customer scenarios to check the conversation flow and eligibility rules.
